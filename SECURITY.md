# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately using [GitHub Security Advisories](https://github.com/aidvgg/n8n-cli/security/advisories/new) for this repository. Do not open a public issue for a security report.

## Handling n8n API Keys

This tool reads and uses n8n API keys to interact with your n8n instance. Never commit API keys, `.env` files, or config files containing credentials to this repository or any fork.

## Supported Versions

Only the latest commit on `main` is supported with security fixes.
